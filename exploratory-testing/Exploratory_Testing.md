# Exploratory Testing

## Test Area

Product Sorting

## Objective

Verify that products can be sorted correctly by name and price.

## Test Environment

- Application: SauceDemo
- Browser: Google Chrome
- Test Type: Exploratory Testing

## Test Scenarios

| Test Scenario | Expected Result | Actual Result | Status |
|---|---|---|---|
| Sort products by Name (Z to A) | Products should be displayed in descending alphabetical order | Products were displayed correctly in descending alphabetical order | Passed |
| Sort products by Price (low to high) | Products should be displayed from lowest to highest price | Products were displayed correctly from lowest to highest price | Passed |
| Sort products by Price (high to low) | Products should be displayed from highest to lowest price | Products were displayed correctly from highest to lowest price | Passed |

## Result

All exploratory sorting scenarios passed successfully.

No defects were identified during this exploratory testing session.
