# Playwright Automation Testing

This folder contains automated end-to-end tests for the SauceDemo web application using Playwright.

## Automation Scope

The automated tests will cover:

- Login
- Product selection
- Shopping Cart
- Checkout

## Tool

- Playwright
- JavaScript
- Node.js

## Test Approach

The automation tests will follow a Page Object Model structure to improve code organization, readability, and maintainability.
