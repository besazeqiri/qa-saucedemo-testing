# Test Plan – SauceDemo

## 1. Objective

The objective of this test plan is to verify that the main functionalities of the SauceDemo application work as expected.

## 2. Application Under Test

Application: SauceDemo

URL: https://www.saucedemo.com/

## 3. Scope

The testing scope includes:

- User Login
- Product Listing
- Product Details
- Shopping Cart
- Checkout
- Logout

## 4. Testing Types

The following types of testing will be performed:

- Functional Testing
- Negative Testing
- Smoke Testing
- Regression Testing
- UI Testing
- API Testing
- Automation Testing

## 5. Test Environment

Operating System:
- Windows

Browser:
- Google Chrome

API Testing Tool:
- Postman

Automation Tool:
- Playwright

Programming Language:
- JavaScript

## 6. Entry Criteria

Testing can start when:

- The application is accessible.
- Test credentials are available.
- The test environment is working.

## 7. Exit Criteria

Testing can be completed when:

- All planned test cases have been executed.
- Critical defects have been reported.
- Regression testing has been completed.
- Automation tests have been executed successfully.

## 8. Risks

Potential risks include:

- Application downtime
- Environment issues
- Unexpected application behavior
- Changes to the test environment.
